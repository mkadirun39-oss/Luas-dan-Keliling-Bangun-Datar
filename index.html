01 KONSEP DASAR

Analisis Grid Satuan (Tab Teori)

Pelajari ketujuh bangun datar pada tab Teori. Perhatikan bagaimana Keliling diukur dengan menyusuri sisi luar kotak satuan (termasuk sisi miring via Teorema Pythagoras $\sqrt{\Delta x^2 + \Delta y^2}$), dan Luas diukur sebagai jumlah persegi satuan $1 \times 1$ di dalam bidang.

Output: Memahami asal-usul rumus luas
02 MODE A SIMULASI

Eksplorasi 7 Bangun & Animasi

Buka tab Simulasi → Mode A. Ubah parameter ukuran melalui slider, lalu jalankan 3 tombol eksperimen: Hitung Kotak Satuan, Telusuri Keliling, dan Bukti Visual Luas (Transformasi ke Persegi Panjang).

Output: Verifikasi konservasi luas bidang
03 MODE B SIMULASI

Konstruksi Geo-Grid Drawer

Beralih ke Mode B: Kanvas Gambar Bebas. Klik titik-titik sudut pada perpotongan grid (snap-to-grid) untuk membentuk poligon sendiri, atau gunakan Preset Cepat lalu geser titik sudutnya (Drag Vertex) untuk mengamati perubahan keliling & luas secara real-time.

Output: Pemodelan poligon koordinat
04 EVALUASI LKPD

Evaluasi & Pembuktian (LKPD)

Selesaikan 7 soal evaluasi berbasis grid satuan pada Bagian A dan tuliskan analisis pembuktian hubungan luas antarbangun pada Bagian B. Klik Cek Nilai lalu unduh atau cetak laporan hasil belajar.

Output: Laporan portofolio Fase F

📊 Ringkasan Prinsip Dasar Kotak Satuan

1. Satuan Panjang (Keliling)

1 sisi kotak grid = 1 satuan panjang. Sisi diagonal yang melintasi $\Delta x$ kotak mendatar dan $\Delta y$ kotak tegak dihitung dengan Pythagoras: $s = \sqrt{\Delta x^2 + \Delta y^2}$.

2. Satuan Luas (Bidang)

1 kotak grid utuh ($1 \times 1$) = 1 satuan luas. Dua potongan segitiga siku-siku setengah kotak yang kongruen bernilai $0,5 + 0,5 = 1\text{ satuan luas}$.

3. Prinsip Konservasi Luas

Memotong bagian suatu bangun datar dan memindahkannya tanpa tumpang tindih tidak mengubah luasnya, namun mengubahnya menjadi persegi panjang yang mudah dihitung.

🎯 Capaian Pembelajaran (Fase F)

Peserta didik mampu memodelkan masalah kontekstual ke dalam bentuk bangun datar pada bidang koordinat/grid satuan, membuktikan rumus keliling dan luas melalui prinsip dekomposisi bidang (konservasi luas) serta Teorema Pythagoras, dan mengaplikasikannya dalam pemecahan masalah geometri secara analitis.

Pengembang: Tim Pengembangan Media Sains & Matematika Digital

Teknologi: HTML5 Canvas 2D, SVG Vector Geometry, Web Audio API Synthesizer

Lisensi: Lisensi Terbuka untuk Pendidikan (Bebas digunakan untuk pembelajaran & praktikum sekolah)

📖 Petunjuk Penggunaan untuk Guru & Peserta Didik

  • Pendekatan Konseptual: Arahkan peserta didik untuk tidak sekadar menghafal rumus, melainkan mengamati bukti visual pemotongan bangun (rearrangement) di Mode A Simulasi.
  • Eksplorasi Mandiri (Geo-Grid Drawer): Pada Mode B Simulasi, peserta didik dapat membuat bangun datar miring atau tidak beraturan di grid dan memverifikasi hasil perhitungan menggunakan rumus koordinat Shoelace & jarak Euclidean.
  • Asesmen Formatif: Gunakan Tab LKPD untuk menguji pemahaman visual serta penalaran deduktif siswa, lalu simpan hasilnya dalam format laporan teks atau cetak fisik.
